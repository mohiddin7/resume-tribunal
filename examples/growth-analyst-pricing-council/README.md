# Growth analyst applying for a senior pricing analyst job

Fictional candidate · Auto mode: the other AIs ran by themselves · 3 AIs from 3 companies · 27 minutes · Real public job posting

A recorded run of Resume Tribunal on a fictional candidate. Recorded by the host as it worked, with the tools in tools/. The host was OpenAI's gpt-6-luna, a fast model, through Codex; it recorded its own model as GPT-6. It did not draft, so the other two AIs wrote the drafts and it merged them. Its last message was trimmed before publishing: the parts written for the recording (seat timings, recording checks and notes on the skill's wording, with local file paths) were removed, and the lines for the candidate kept.
