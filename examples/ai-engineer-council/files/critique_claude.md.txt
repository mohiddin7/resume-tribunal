# Resume review: AI Engineer, Stripe Solutions Architecture (Chicago)

**Assumptions:**
- Nothing in the candidate's material is dated after December 2023, so I'm treating January 2024 to today as unaccounted for. A recruiter will ask about it.
- The candidate is in Seattle, and neither draft mentions Chicago or relocation.

**Must-haves neither draft can show, because the material doesn't contain them:**
- 4+ years shipping production systems. The material has about 2 years as an analyst, a research assistantship and a 3-month internship.
- Backend engineering or debugging across services.
- AI agents or LLM tools beyond fine-tuned classifiers.
- A second language from Ruby, Node.js or Next.js. Only Python is evidenced.
- Deployment and monitoring of a service.

Rewording won't close these gaps.

## Draft K

**Screen decision:** No. There is no production software engineering or LLM/agent work, and the role requires 4+ years of it.

**Level:** Entry-level data analyst or new-grad data scientist.

**Findings:**

1. **Consider:** "Python, SQL; AWS S3, AWS EC2, AWS QuickSight; GCP; SQL Server, SSMS; Excel, Tableau; Natural Language Processing (NLP), CNN, Yolov7"
   It's a single unbroken string that's hard to scan, and it leaves out Linux and the transformer models, which are the candidate's closest signals to the role.

2. **Fix:** "Classified news using DeBERTa, RoBERTa and DistilBERT; RoBERTa had the highest f1-score of 0.9916."
   Dropping "as real or fake" hides what the task was, and a near-perfect F1 with no dataset context will make a hiring manager suspect leakage.

3. **Consider:** "Trained models using AWS EC2 and GCP compute engines, reducing runtime by 80%."
   The 80% has no baseline (versus local training? a CPU?), so it reads as unverifiable.

4. **Fix:** "Created AWS QuickSight dashboards to monitor model performance, runtime and computational resources, resulting in a 20% increase in overall model efficiency."
   A dashboard doesn't make a model more efficient, so the causal claim invites doubt.

5. **Consider:** "Built an interactive web application to detect diseased cotton plants, resulting in a 100% increase in user interaction."
   This is the only thing on the page that shows the candidate building an application, yet it names no stack, and "100% increase in user interaction" means little for a personal project.

6. **Consider:** "Learned sales procedures and customer support tools by shadowing meetings between Solutions Architects and 4 different customers."
   "Customer support tools" shifts the original "tools available to assist customers" toward helpdesk software, which the material doesn't say.

7. **Consider:** "Collaborated on monthly reports using Excel and analytical writing; publications doubled and donor funds increased by 45%."
   Tying a 45% rise in donor funds to report collaboration is an attribution a hiring manager will question.

8. **Fix:** "Data Science Masters Candidate (CGPA: 3.95/4) | Dec 2023"
   Nearly three years later, "Candidate" reads as either an unfinished degree or a stale resume, and the material doesn't say which.

**Areas with no material problems:** Bullet order works: automation bullets lead each role. No team work is written as the candidate's alone, and nothing reads as copied from the job description.
