# Data scientist applying for an AI engineer role

Real resume, shared with consent · Auto mode: the other AIs ran by themselves · 3 AIs from 3 companies · 27 minutes · Real public job posting

A recorded run of Resume Tribunal on a real candidate who agreed to publish their de-identified resume. Recorded by the host as it worked, with the tools in tools/. The host was OpenAI's gpt-6.1-sol, through Codex; it recorded its own model as GPT-6. It also wrote a draft, so the merge ran in a Codex sub-agent that started with none of the host's conversation and read only the merge prompt. Its last message was trimmed before publishing: the parts written for the recording (seat timings, recording checks and notes on the skill's wording, with local file paths) were removed, and the lines for the candidate kept.
