# BI analyst and data engineer applying for a data engineer role

Real resume, shared with consent · Manual mode: pasted into other AI apps · 3 AIs from 2 companies · 21 minutes · Real public job posting

A recorded run of Resume Tribunal on a fictional candidate. Recorded live. Where the candidate pasted a card into ChatGPT or Gemini, the paste went to the same company's model through its command-line tool (OpenAI's GPT-6 Astra for ChatGPT, Google's Gemini 3.8 Flash for Gemini), and the reply was pasted back unedited.
