## 4. Fixes

1. **"Data Science Masters Candidate (CGPA: 3.95/4) | Dec 2023"**: Dec 2023 is nearly three years ago, so say whether the degree was conferred (e.g. "M.S., Data Science, Dec 2023"). "Candidate" reads as unfinished.
2. **"**Graduate Research Assistant** | Nov 2022 - Dec 2023"**: This is the latest date on the page. Add any work, contract or project since Jan 2024 above it. If there was none, add a one-line note on how the time was spent, because an unexplained gap of almost three years will end the screen.
3. **"Seattle, WA | <<EMAIL>> | <<PHONE>>"**: The role is in Chicago. If the candidate is willing to relocate, say so on this line.
4. **"Designed and tested over 30 ML models using AWS S3 and AWS EC2; increased accuracy by 14% and decreased runtime by 25%."**: Restore "to find the best model" and name the baseline the 14% and 25% are measured against. Without it, the line implies building 30 models caused the gain.
5. **"Created AWS QuickSight dashboards to monitor model performance, runtime and computational resources, resulting in a 20% increase in overall model efficiency."**: Dashboards don't make models more efficient by themselves. Say what was changed based on what they showed and what "efficiency" measured, or drop the 20%.
6. **"Built an interactive web application to detect diseased cotton plants, resulting in a 100% increase in user interaction."**: A personal project has no baseline for a "100% increase." Replace the metric with the app's stack and how it was deployed, if the candidate can state that truthfully. This is the only line hinting at shipping software.
7. **"Collaborated with the IT team to implement secure, reliable data management and reporting systems using SQL Server and Tableau, reducing report generation time by 70%."**: Name the candidate's own part, such as the schema, the jobs or the dashboards they built, as distinct from IT's. This is the closest thing on the page to backend systems work.
8. **"Designed Tableau dashboards to monitor KPIs and expenditure, resulting in improved budget allocation, annual savings of 800K rupees and enhanced stakeholder retention."**: Cut "enhanced stakeholder retention," which is unmeasured. Say whose savings the 800K rupees were and how they were traced to the dashboards.

## 5. Claim-defence questions

1. **"The QuickSight dashboards gave a 20% increase in model efficiency. What metric was that, and what did you change after seeing the dashboards?"** Tests whether there is a real causal link between monitoring and the result.
2. **"Across the 30 models, what was the starting model, and was the 14% accuracy gain just picking the best one? Was this your project alone or a team's?"** Tests the baseline, the measurement and the candidate's own share of an intern project.
3. **"The PDF invoice automation: how many invoices, what library, how did you handle malformed PDFs, and who ran it after you left?"** Tests whether this was a durable tool others relied on or a one-off script. That distinction is central to this role.
4. **"On the SQL Server and Tableau reporting system with IT, what did you build and what did IT build? How was the 70% measured?"** Tests the candidate's own part and the measurement.
5. **"How did you attribute the 800K rupees in savings and the 45% rise in donor funds to your dashboards and reports?"** Tests whether the candidate claims outcomes they can actually trace to their own work.
